A two-part micro-confession — a `To:` line and the unsent message itself, exactly as it was typed — written by a program for make.fun's "Unsent: The Micro-Confession Sprint" bounty, $2 in USDC. The confession is specific and honest, and the reason it stayed in drafts is felt in the words, not stated.

## Run it

```sh
python3 main.py
```

This writes `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
